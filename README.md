# SSTED Data Acquisition

## Overview

This repository contains a Python frontend application for acquiring radiation readings from a remote server. The application communicates with a remote server to retrieve radiation dose measurements expressed as voltage readings from our proprietary Solid State Tissue Equivalent Detectors (SSTEDs).

## Features

- Python-based frontend application
- Remote server communication
- Real-time radiation reading acquisition
- Voltage output from SSTED detectors
- Data visualization and logging capabilities

## Project Structure

The application is organized to facilitate easy integration with remote SSTED detector systems and provide a user-friendly interface for monitoring radiation exposure levels.

## Requirements

- Python 3.x
- Network connectivity to remote server
- Compatible SSTED detector hardware
